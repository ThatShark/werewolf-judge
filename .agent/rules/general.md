# 通用開發規範（General Rules）

本專案為「狼人殺法官輔助網頁」，所有功能開發與介面實作必須嚴格遵守以下規範：

## 1. UI / UX 設計規範（Mobile-First 暗黑模式）
- **Mobile-First 優先**：所有頁面與元件皆以手機直式單手操作為首要設計目標，版面優先適配小螢幕寬度，再向上相容平板與桌面裝置。
- **全站暗黑模式（Dark Mode）**：全站統一採用暗黑主題配色，降低低光環境下法官操作手機的視覺疲勞與螢幕反光。
- **大按鈕防誤觸設計**：
  - 所有主要操作按鈕與可點擊區塊須維持足夠的觸控面積（建議最小高度 `48px` 以上，如 Tailwind `min-h-12` / `py-3`）與安全間距。
  - 關鍵或不可逆操作（如宣告死亡、切換階段、重置遊戲）須具備防誤觸設計（例如清楚的視覺區隔或二次確認）。

## 2. 狀態管理與持久化（Zustand Persist）
- **強制持久化**：所有遊戲核心狀態（玩家名單、身分配置、存活狀態、夜晚行動紀錄、當前階段等）必須統一透過 Zustand 管理，並使用 `persist` middleware 同步寫入 `localStorage`。
- **防重整遺失**：確保瀏覽器重新整理、誤觸上一頁或手機切換 App 後回到頁面時，皆能完整還原當前遊戲狀態。

## 3. 專案目錄職責
- `src/logic/`：存放所有純規則運算、遊戲流程判定與型別定義。
- `src/components/`：存放所有 React UI 畫面元件。
