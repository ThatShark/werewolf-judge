# `/verify` 驗證工作流

執行以下步驟驗證專案健康度與行動版渲染狀態：

1. **執行單元測試**
   執行 `npm run test`，確認所有 Vitest 單元測試皆通過。

2. **執行專案建置**
   執行 `npm run build`，確認 TypeScript 型別檢查與 Vite 正式打包無任何錯誤或異常。

3. **啟動本機預覽並以手機螢幕尺寸檢查首頁**
   - 啟動本機伺服器（`npm run preview` 或 `npm run dev`）。
   - 使用瀏覽器開啟首頁網址，並將視窗尺寸模擬為手機螢幕（例如 `390x844`）。
   - 檢查以下項目：
     - 首頁是否正常渲染，無白屏或 Console 報錯。
     - 是否正確呈現 Mobile-First 暗黑模式版面，且無水平溢出破版。
     - 按鈕與互動元件尺寸是否易於手機點擊。
   - 檢查完成後停止伺服器，並向使用者回報測試、建置與畫面檢查結果。
