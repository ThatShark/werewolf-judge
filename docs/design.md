# 狼人殺法官輔助網頁 — 視覺與資訊減法設計規範（Matte Tactical Dark）

> **風格定位**：瑞士極簡工具（Swiss Minimalist Tool） × 霧面戰術暗黑（Matte Tactical Dark）
> **資訊減法原則**：**只顯示當下 3 秒內做決策需要的資訊**。所有解釋性副標題、重複提示、百科長文與非當下操作一律移除或收斂至抽屜。
> **最高架構鐵律**：本次為純視覺與 UI 結構重構，**嚴禁修改 `src/logic/` 內的任何規則引擎程式碼**，確保既有 23 個測試檔、153 個單元測試全數維持通過。

## 1. 去 AI 味視覺禁止清單（Strict Anti-Patterns）

所有樣式與元件（`src/index.css`、`src/App.tsx`、`src/components/**`）必須嚴格遵守以下禁止條款：

| 禁止項目 | 具體反例（須徹底清除） | 規範替代方案 |
| :--- | :--- | :--- |
| **1. 禁止背景漸層** | `bg-gradient-to-br`、`from-amber-500/20 via-slate-900` | 一律使用 3 層霧面炭黑純色階層（`#0C0E12` / `#14171D` / `#1D212A`）。 |
| **2. 禁止霓虹發光重陰影** | `shadow-indigo-*`、`shadow-amber-*`、`shadow-emerald-*`、`shadow-lg`、`shadow-2xl`、`ring-*` | 全站零發光、零投影；僅靠「底色明度差」與 `1px` 極細分隔線區分層級。 |
| **3. 禁止毛玻璃** | `backdrop-blur-md`、`backdrop-blur-xs` | TopBar 採實色 `#14171D`；彈窗／抽屜遮罩採純黑霧面 `rgba(0, 0, 0, 0.78)`。 |
| **4. 禁止卡片套卡片（Card-in-Card）** | `rounded-2xl border bg-slate-900` 內再嵌套 `rounded-xl border bg-slate-950` | 同區域最多 **1 層**表面容器；子區塊改用 `1px` 細線（`divide-y` / `border-t`）切分。 |
| **5. 禁止過度圓角氣泡感** | `rounded-2xl`、`rounded-3xl`、無意義 `rounded-full` 徽章 | 收斂至銳利工業圓角：按鈕／輸入框／座位條 `rounded-md`（`6px`），面板／彈窗 `rounded-lg`（`8px`），底部抽屜頂角 `rounded-t-xl`（`12px`）。 |
| **6. 禁止重複 Emoji 與解釋性副標題** | 按鈕與標題下方的教學小字、重複裝飾 Emoji（`📋`、`❓`、`📜`、`👥`、`⚖️`、`🗣️`、`👮`、`🎤`、`🗳️`） | 按鈕限 2–4 字純文字（僅少數高辨識入口如 `⚡ 觸發技能` 保留單一符號）；刪除標題下方解說副標題。 |
| **7. 禁止未授權色相與藍調灰** | `slate-*`、`indigo-*`、`sky-*`、`violet-*`、`cyan-*`、`orange-*` | 全站嚴格鎖定「3 層中性霧面炭黑 ＋ 4 種語意功能色」。 |

## 3. 3 階字級與等寬數字（`tabular-nums`）

### 3.1 嚴格三階字級

全站常規 UI 鎖定 3 個字級，廢除 `text-[10px]`、`text-[11px]`、`text-base`、`text-2xl` 等零散字級：

| 階級 | 尺寸 / 行高 | 字重 | 使用場景 |
| :--- | :--- | :--- | :--- |
| **T1 主標／計時階** | `18px` / `24px` (`text-[18px] leading-6`) | `font-semibold` (600) | 階段主標、當前步驟角色名、抽屜／彈窗標題、主要計時數字（倒數主讀數與傳閱底牌角色名可依比例放大且維持等寬對齊）。 |
| **T2 正文／操作階** | `14px` / `20px` (`text-[14px] leading-5`) | `font-medium` (500) / `font-semibold` (600) | 座位名稱與座號、主要按鈕、提詞台詞、清單主項、輸入框文字。 |
| **T3 狀態／輔助階** | `12px` / `16px` (`text-[12px] leading-4`) | `font-medium` (500) | 次要狀態標記、進度數字（`2 / 7`）、附加票 `+1`、TopBar 工具鍵、規則簡述。 |

### 3.2 強制等寬數字（`tabular-nums`）

所有數字顯示**一律強制套用 `tabular-nums`**（`font-variant-numeric: tabular-nums`），避免倒數或票數更新時版面晃動：
- 發言倒數計時器（`01:30`）與緩衝秒數（`05s`）
- 座號（雙位補零或固定等寬對齊 `01`～`15`）
- 投票票數（`3.5`、`+1`）、步驟進度（`2 / 7`）、存活數（`10/12`）

## 4. `100dvh` 單屏高度分配與「單一主按鈕（Single Primary CTA）」鐵律

### 4.1 零滾輪單屏架構

- 遊戲中所有核心畫面維持 `h-dvh w-full overflow-hidden flex flex-col`，絕不產生全頁滾軸：
  - **TopBar**：固定 `52px`（`shrink-0`），`bg-[#14171D]`，`border-b border-white/8`。
  - **主工作區**：`flex-1 min-h-0 flex flex-col gap-2 overflow-hidden`，內部保留左右對稱雙欄座位網格（左欄 `1..ceil(N/2)`、右欄 `ceil(N/2)+1..N`），單格高度 `>= 48px`（`min-h-12`）。
  - **底部固定操作區**：固定 `shrink-0`，`border-t border-white/8`，高度約 `56px`–`60px`。

### 4.2 單一主按鈕原則（Single Primary CTA）

- **每屏底部操作區最多僅有 1 顆高對比實心主按鈕**（`min-h-12`，`14px font-semibold`）：
  - 預設推進：實心警徽琥珀 `bg-[#F5A623] text-[#0C0E12]`
  - 天亮結算：實心好人綠 `bg-[#30A46C] text-[#0C0E12]`
  - 高危不可逆確認：實心狼紅 `bg-[#E5484D] text-[#F3F4F6]`
  - 禁用態：`bg-[#1D212A] text-[#6B7280] cursor-not-allowed`
- 其餘次要操作一律降階為「極簡線框鍵（`border border-white/8 bg-[#14171D] text-[#9CA3AF]`）」或收進右上角選單／抽屜，絕不與主按鈕搶奪視線。

## 5. 全站 6 大畫面「資訊減法清單」（強制執行）

### 5.1 大廳與板子選擇（`BoardSelectScreen`、`SeatSetupScreen`）
- **移除「⚡ 100% 自動結算」徽章**（全站板子已全面支援，此徽章無區別意義）。
- **板子選擇清單極簡化**：板子選擇卡片上**徹底隱藏首夜／次夜睜眼順序、長篇職業介紹與 Q&A 題數**，每列僅顯示：
  - **板子名稱** ＋ **人數**（`12人`）＋ **陣營簡稱**（如 `4狼 4神 4民` 或 `4狼 4神 3民 1三方`）。
  - 詳細規則、角色介紹與睜眼順序僅在點開 `規則/Q&A` 抽屜時顯示。
- **大廳主畫面減法**：主畫面只留「**已選板子摘要（含切換板子鍵）＋ 確認座位（雙欄座位與人數／暱稱）**」；將以下項目全面收納進點擊「**開局設定**」才展開的抽屜／彈窗：
  - 進階主持矩陣（實體／線上發牌 × 實體／線上法官 × 單機／多機、語音 TTS 與緩衝秒數）
  - 特殊房規微調（女巫自救、屠邊／屠城、警長與吞警徽規則等）
  - 特殊板子配置（如《開膛手傑克》雙板的性別與第二身分分配）
  - 夜間環境白噪音設定

### 5.2 發牌與傳閱（`PassAndRevealScreen`）
- **刪除底牌下方的長篇職業百科與重複說教文字**。
- 翻開底牌後僅顯示 3 項核心資訊：
  1. **超大角色名稱**（搭配所屬陣營語意色線條或純色標籤）
  2. **一句話核心能力（嚴格控制在 15 字內）**
  3. **狼隊友座號**（僅狼隊成員可見，等寬數字呈現）

### 5.3 夜間控制台（`NightConsoleScreen`、`NightStatusBanners`、`OnlineJudgeOverlay`）
- **移除整晚步驟總覽清單／冗長進度條文字**：頂部僅顯示**當前步驟角色名**與右上角等寬進度數字（如 `2 / 7`）。
- **頂部多層警告橫幅收斂**：將 `NightStatusBanners` 及相關狀態提示收斂為「**單行狀態膠囊列**」（如 `禁言 03`、`石化 07`、`換票`），點擊膠囊才於彈窗／抽屜展開詳情，避免佔據主屏高度。
- **極簡左側 `2px` 指示線提詞機**：
  - 實體法官模式：改為無外框、僅具左側 `2px` 指示線（`border-l-2 border-[#F5A623]`）的霧面條帶，右側提供線框 `台詞` 鍵展開完整逐字稿抽屜。
  - **保留已出局假裝操作紅字警告**：採左側 `2px` 緋紅指示線（`border-l-2 border-[#E5484D]`）＋ 精簡單行紅字警示，絕不跳過已出局角色步驟。
  - **線上語音法官模式**：隱藏三段式大字逐字稿，只顯示**一句極簡操作指令**（如「請選擇今晚落刀目標」）。
- **複雜技能改為 Bottom Action Sheet**：雙目標交換（魔術師、狼巫換位等）、三目標未明之霧（煉金魔女）、協助者勾選（覺醒女巫）等複雜控制項，統一改為點選座位後從底部彈出／展開的精簡操作盤（Bottom Action Sheet），絕不擠壓中央雙欄座位網格。

### 5.4 白天死訊公告與日間技能（`DayAnnouncementScreen`、`DayBurstSkillsPanel`、`ExtraDaySkillsSection`）
- **防法官唸錯鐵律**：
  - 主公告大字**只顯示「昨晚死亡：03 號、08 號」**（或「昨晚平安夜」）。
  - **預設隱藏真實死因**（狼刀／毒殺／奶穿／殉情等），僅在座號旁放置極小灰色資訊圖示（或點擊該列後才展開法官視角死因與身分），徹底防止法官早上順口唸出死因。
- **技能觸發整合抽屜**：
  - 將所有日間主動／延遲爆發技能（騎士決鬥、白狼王自爆帶人、愚言家／鐵好人翻牌、偵探指證、潘朵拉手槍、法老之蛇救活、白貓／老流氓延遲觸發等）收斂為一顆**「⚡ 觸發技能（N 項可用）」整合抽屜按鈕**。
  - 外層僅保留最常用的「**狼人自爆**」直接操作，不再將所有角色技能面板平鋪佔滿畫面。

### 5.5 白天放逐投票（`DayVoteScreen`、`ExileVotePanel`）
- **刪除投票教學橫幅與附加票數整行說明文字**。
- **座位右側大號票數**：直接在雙欄座位右側以醒目 `tabular-nums` 顯示當前得票數，若有烏鴉／管家／狼僕／手動附加票，僅於票數旁顯示極簡 `+1`（或 `-1`）小標記。

### 5.6 所有抽屜與彈窗（`SlideDrawer`、`ConfirmModal`、`RestartModal`、`ManualVictoryModal`、`QADrawer`、`HistoryDrawer`、`NotebookDrawer`、`SeatStatusDrawer`）
